# CODSOFT – Java Development Internship

A collection of Java development projects completed as part of my **CODSOFT Internship**.

This repository contains beginner-friendly Java applications developed to strengthen programming fundamentals, object-oriented programming, problem-solving, and practical application development.

---

## Projects

### 1. Number Guessing Game

A console-based Java game where the user attempts to guess a randomly generated number.

**Key Concepts:**

* Random number generation
* User input handling
* Conditional statements
* Loops
* Attempt tracking

**Files:**

* `NumberGuessingGame.java`

---

### 2. Student Grade Calculator

A Java application that calculates a student's total marks, average percentage, and corresponding grade based on subject marks.

**Key Concepts:**

* User input
* Arithmetic operations
* Conditional statements
* Grade calculation
* Basic Java programming

**Files:**

* `StudentGradeCalculator.java`

---

### 3. ATM Interface

A console-based ATM simulation that provides basic banking operations through a menu-driven interface.

**Features:**

* Check account balance
* Deposit money
* Withdraw money
* Exit the application

**Key Concepts:**

* Object-Oriented Programming
* Classes and objects
* Methods
* Encapsulation
* Conditional statements
* Loops
* User input handling

**Files:**

* `ATM.java`
* `BankAccount.java`
